# Privacy

Subnautica 2 Mod Manager is a local desktop utility.

- It does not upload files, logs, diagnostics, paths, or mod data.
- Support reports are generated locally and redact user-home path portions where possible.
- No Nexus, Steam, or web API integration is active in the current build.
- Runtime data is stored under `%LOCALAPPDATA%\Subnautica2ModManager` in packaged mode and under the repo root in source mode.

Users choose what to share if they copy diagnostics or logs into a bug report.
